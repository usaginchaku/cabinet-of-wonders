# v0.3 投資と育成のプレイ調整

## 実際に遊んで見つけた問題

ブラウザの独立した新規セーブで旧版を8営業日進め、増築、学芸員Lv.3、工房Lv.2まで到達した。開館は4倍速で自然閉館させ、資金・所持品・時刻の注入はしていない。

- 入館料だけが収入源で、人数が上限になると展示の魅力を上げても売上が変わらなかった。初期配置にオルゴールを追加した同条件比較では、照明420 Gへの投資で日利益が451→436 Gへ下がった。
- 増築は配置面積だけを増やし、展示を追加しない限り維持費20 G分だけ利益が減った。
- 学芸員Lv.2/3は接客人数を増やさず、Lv.3の魅力増加で混雑が悪化する場合があった。旧版の通しプレイでは育成後も44人のまま、7日目の満足度は61%。
- 展示を最終改良する費用が中盤の収入に対して安く、どの品を仕上げるかを選ぶ余地が薄かった。
- 改良の効果が購入前に比較できず、展示台の見た目もほとんど変わらなかった。

## 変更

- **鑑賞と回転の役割**: 入館料に加えて、展示1点あたりの魅力に応じた寄付が入る。人数が同じでも品質向上には収入の効果がある。寄付・入館料・初公開支援金を精算画面で分ける。
- **広さと接客の役割**: 受入人数は接客枠と通路の広さの小さい方。入口から歩ける床1区画が3人分になる。増築だけでなく、無料の配置整理にも効果がある。
- **学芸員の育成**: 接客枠はLv.1/2/3で+4/+8/+12人。既存の開館中の調査、日数短縮、魅力強化も維持。
- **投資比較**: 改良・設備・育成の利益差、受入人数差、変化する満足度を事前表示。条件未達の育成も効果を確認できる。配置候補にも人数・満足度を表示。未確定プレビューは保存しない。
- **収集の達成**: 完成したテーマを初めて営業で披露すると500 G。各テーマ1回限り。通常の営業利益とは分け、工房の小仕事や再配置では重複しない。
- **資金の選択**: 調査費はその場所で発見した点数に応じて増える。最初の展示改良費は維持し、Lv.3への最終改良費は650 + 基礎魅力×12 Gに調整。例: 時計は初回166 G、最終866 G。
- **成長の見た目**: 展示台をLv.1の生成り、Lv.2の青緑、Lv.3の深緑と金装飾に変化させ、収蔵庫のサムネイルにも反映。
- **操作**: タブや詳細を切り替えたらパネルを先頭へ戻す。同じ画面での更新では位置を保持。手前の展示の透明な判定枠が、奥の見えている品のクリックを奪う問題を修正。

改修途中の新規10日プレイで、人気増加に対する混雑の減点が強すぎることも確認した。減点を最大24ポイントに抑え、質の高い展示の効果が混雑だけで消えないようにした。満員時に受け入れられない人数と売上の差は残る。45 Gの価格は客層と混雑によって有利になり得るが、常に最適になるものではない。

## 検証方法と判断の限界

最終版の通しプレイは `artifacts/final-playthrough.cjs`、記録は `artifacts/playthrough-final.json`。すべて新規ブラウザのUI操作で進行し、12営業日を自然閉館させた。5日目に初増築、7日目に学芸員Lv.3、10日目に56区画、11日目に3テーマの初公開まで到達。12日目終了時は14品を収集済み。システムの境界値や異常なセーブの検証は、別のエンジン・ブラウザテストで行う。

独立レビューにはClaude Codeを読み取り専用で使用。配置で通路が減ること、投資による満足度の変化、条件未達時の育成効果の非表示を修正した。単純な値上げの禁止は採用せず、客層と混雑に応じて料金を選ぶ余地を残した。

15品の小規模ゲームという範囲は維持。最適な投資順や長期間の面白さを保証する検証ではない。全収集・全改良後の新シナリオや、無期限に資金を使う新機能は追加していない。

## 保存と公開

- 保存キーと既存のversion 2形式を維持。v1移行、過去の営業記録、進行中の調査・修復を維持する。
- `milestones` は初公開済みテーマの記録に利用。旧セーブでは空配列として補完するため、既に完成していたテーマも更新後に一度だけ支援金を受け取れる。
- 開館中の読み込みでは、既存仕様どおり検証済みの配置・設備から売上予測を再計算する。収支ルールの変更により、更新前と利益・人数が変わる場合がある。通路の広さとプレビューで確認できる。
- API・認証・課金・データ送信・依存パッケージの追加なし。GitHub PagesのHTTPSと配信ファイルの許可リストを維持。
- ロールバックは変更コミットのrevertで行う。支援金の受領記録を旧版が保持しないため、繰り返し旧版と新版を行き来する運用は想定しない。セーブのファイル書き出しを保持する。
