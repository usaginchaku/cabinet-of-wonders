# 奇妙な収集館

収集・修復・展示・営業を繰り返し、自分の収集館を育てるWebゲームです。

## 遊ぶ

**[ブラウザで遊ぶ](https://usaginchaku.github.io/cabinet-of-wonders/)** — スマホ・PC対応。インストール不要です。

## ローカルで動かす

Windowsで **`遊ぶ.cmd` をダブルクリック**してください。Node.js 20以降が必要です。ブラウザに `http://127.0.0.1:4173` が開きます。

ターミナルから起動する場合:

```sh
npm start
```

`index.html` の直接ダブルクリックではES Modulesが動かないため、上記のローカルサーバーを使います。サーバーは127.0.0.1にのみ接続し、LANやインターネットには公開しません。インストール・外部サービス・APIキー・課金は不要です。

ポートが他のアプリと重複するときは `node server.mjs --port 4174` を実行して `http://127.0.0.1:4174` を開けます。セーブはURLごとなので、普段のURLから先に書き出してください。

## 遊べる内容

- 15種類の収蔵品。からくり、旅の記憶、奇妙な遺物の3テーマ。
- 展示・移動・収蔵、通路判定、同テーマの隣接効果。
- 3段階の展示改良。最初の改良で鑑賞重視 / 回転重視を選択。
- 入館料と客層を考えた営業、売上・維持費・満足度・評判。
- 修復工房、3つの調査先、照明、ベンチ・植物、20→30→42区画への増築。植物とベンチは移動・撤去でき、撤去時に半額を回収。
- 5段階の操作チュートリアル、遊び方、営業記録。
- 自動保存、JSONの書き出し・読み込み、直前バックアップ、複数タブ競合の検出。
- 1回18秒の営業。早送り可。非表示タブ・説明画面では進行を一時停止。

セーブはブラウザのローカルストレージに保存されます。別PC・別ブラウザへの移動やブラウザデータの削除前は、設定から書き出してください。自動バックアップは同じブラウザ内の直前保存1つで、外部バックアップの代わりにはなりません。

## 開発・検証

ランタイム依存パッケージなし。HTML / CSS / JavaScript ES ModulesとNode.js標準HTTPサーバーで動きます。

```sh
npm test
```

UI検証は `tests/browser.test.cjs`。PlaywrightとChromiumがある環境で `PLAYWRIGHT_MODULE_PATH` にパッケージの絶対パスを指定して実行します。結果とスクリーンショットは `artifacts/` へ保存します。

実時間タイマー・キーボード・連打・確認画面を開いた後のタブ競合は `tests/interaction.test.cjs`。両テストとも起動済みのローカルサーバーを使い、個別のブラウザプロファイルで実行するため、普段のセーブには触れません。Chromeが標準以外の場所にある場合は `MUSEUM_BROWSER_PATH` も指定します。

設計方針と実装範囲は `docs/DESIGN.md`、検証結果は `docs/VERIFICATION.md` を参照。

## 公開

`npm run build` はゲームに必要な12ファイルだけを `dist/` に出力します。`main` へのpush時にGitHub Actionsがテスト・ビルド・GitHub Pagesへの公開を行います。テスト結果、スクリーンショット、開発用サーバー、ローカルのセーブファイルはサイトに含めません。

セーブはURL・ブラウザごとです。ローカル版から続ける場合は、ローカル版の設定で書き出し、公開版の設定で読み込んでください。

## 素材

ジオラマと収蔵品はこのゲーム用の独自SVG図案。ジョジョのモチーフはファン創作の展示模型として収録し、公式画像・音声は使っていません。非公式の個人向けゲームです。操作アイコンはLucide（ISC、`assets/LUCIDE-LICENSE`）。効果音はWeb Audioによる短い合成音です。
